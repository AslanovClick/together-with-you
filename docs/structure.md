# Структура лендинга (утверждено 2026-10-26)

Логика: Ми → Для кого → Що робимо → Результат → Доказ довіри → Як долучитися.
Только украинский. Статика (без CMS на старте). Mobile-first, должно быть удобно на телефоне.

1. **Header**: sticky, низкий. Лого · Про нас · Напрями · Проєкти · Актуальне · Контакти · кнопка «Підтримати». На мобайле бургер.
2. **Hero**: статичный заголовок + 3–4 реальных фото с мягкой сменой. Не скучный однотипный коллаж — нужна интересная композиция (круги из лого как маски/рамки фото). Плашка «📍 Лиманівка, Лозівська громада». CTA: «Підтримати фонд» (основная), «Як долучитися».
3. **Про нас**: история (2022 → переезд из Харькова → волонтёрство → фонд с 04.2024), команда (Юлія, Софія, Дарина), миссия крупной типографикой. CTA «Дізнатися про фонд» ведёт в Instagram.
4. **Для кого**: 5 карточек, описания видны сразу (без hover).
5. **Що робимо**: 6 направлений. Клик по направлению ведёт к проектам с этим фильтром.
6. **Цифри**: только реальные (4 роки, 300+ заходів, 450+ учасників, 18 округів, 212 038 грн). Оформить интереснее, чем просто полоса.
7. **Проєкти**: фильтры = 6 направлений. Сначала 6 карточек, остальные по кнопке «Показати ще». Только проекты для громады.
8. **Живе життя спільноти**: editorial-галерея; на мобайле горизонтальный свайп.
9. **Розвиваємося і звітуємо**: Команда / Організація / Досвід, проекты развития фонда (Ресурсний центр НДО, Razom сильніші), сертификаты, аудит, годовые отчёты. Просторно и понятно, не сжато.
10. **Партнери**: логотипы одинакового визуального веса.
11. **Підтримати фонд**: суммы 100/300/500/1000/інша, ежемесячно, реквизиты с копированием, ссылка на блок 9. Без манипулятивных формулировок.
12. **Актуальне**: табы «Новини | Медіа про нас», 3–4 материала.
13. **Долучайтеся + Контакти**: 4 роли (учасник, волонтер, партнер, благодійник) с действиями, контакты, соцсети, карта.
14. **Footer**: лого, описание, навигация, контакты, соцсети, «Підтримати», политики, ЄДРПОУ.

## Визуал
- Шрифты: Unbounded (заголовки), Mulish (текст).
- База: светлый фон, `#0d2f9c` для текста, `#5271ff` для действий. `#ffc368`, `#ff5757`, `#cb6ce6` только акцентами.
- Фирменный мотив: полупрозрачные пересекающиеся круги из лого (opacity ~0.75). Развивать его по сайту: фоны, маски фото, иконки направлений, декор.
- Иконки: один пак (Phosphor или Lucide).
- Анимации лёгкие.
