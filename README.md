# Спільно з тобою — лендинг

Статический сайт на [Astro](https://astro.build). На выходе чистый HTML/CSS/JS в `dist/`, который можно залить на любой хостинг.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # сборка в dist/
```

## Где что лежит

| Что | Где |
|---|---|
| Весь текст и контент (проекты, цифры, новости, партнёры, реквизиты) | `src/data/site.ts` |
| Иконки (Phosphor) | `src/data/icons.ts` |
| Блоки страницы | `src/components/*.astro` |
| Цвета, шрифты, общие стили | `src/styles/global.css` |
| Интерактив (меню, фильтры, донат, табы) | `src/scripts/main.ts` |
| Фото и документы | `src/assets/photos`, `src/assets/docs` |
| Лого (вектор, перерисовано 1:1) | `src/assets/logo` |

## Как заменить фото

Положите оригинал в `src/assets/photos/` под **тем же именем** (например, `optimists.jpg`). Astro сам сожмёт его и нарежет размеры в WebP.
Пока стоят временные фото из презентации шириной около 430 px. Список нужных оригиналов: `docs/photos.md`.

## Что ждём от фонда

Все места-заглушки помечены в `src/data/site.ts` комментарием `TODO`. Значение `null` скрывает элемент на странице.

- Ссылки на оплату (`support.oneTimeUrl` / `monthlyUrl`). Пока их нет, кнопка доната ведёт к реквизитам.
- ЄДРПОУ, IBAN, банк.
- Telegram, YouTube.
- Логотипы партнёров. Пока вместо них плашки с названиями.
- Годовые отчёты в PDF, PDF аудита и сертификатов.
- Реальные новости и материалы «Медіа про нас».
- Домен (`astro.config.mjs`) и страница политики конфиденциальности.

Полный список вопросов: `docs/questions-for-fund.md`.
